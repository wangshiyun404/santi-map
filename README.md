# 三体·阅读地图

网页 3D 叙事游戏：沿一条星河走过三部曲 41 座岛（《三体》13 站、《黑暗森林》14 站、《死神永生》14 站），看懂每一部的故事线。面向小学高年级起的孩子与无技术背景的文科生。

**在线试玩**：https://wangshiyun404.github.io/santi-map/ （建议 Chrome/Edge/Safari，进入后点"小学生模式"或"读者模式"，声音随之启动）

- 开发说明（必读）：`CLAUDE.md`　设计规格：`DESIGN.md`　进度：`PROGRESS.md`
- 运行：`python3 -m http.server 8975 --directory .` → http://localhost:8975
- 构建单文件/Artifact：`python3 build.py` → `dist/`
- 纯前端、零外网依赖（three.js r128 本地）。
